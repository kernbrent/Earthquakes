# NTX Earthquakes team admin

Prepared for `https://ntxearthquakes.com/admin/`. This new, separate Cloudflare Worker and SQLite-backed Durable Object provide authenticated calendar, roster, and game-result editing. It does not use an existing business database or consume a new D1 slot. Existing public HTML and the Club Fees page at `admin.html` remain intact. Exact Worker routes cover only `/admin`, `/admin/*`, `/api/site-admin/*`, and the three existing `/data/*.json` resources.

Migration 0002 seeds the current public JSON without changing its records. Public read routes return the current stored arrays, so the existing website's calendar scripts consume admin edits without rebuilding the public site. Private read/write APIs require an eight-hour authenticated session. Writes also require same-origin requests and the session's CSRF token. Updates require the last-read revision to prevent lost concurrent changes. Plain-text fields reject HTML and unknown fields; dates, numbers, and jersey-number arrays are validated. The initial admin username is `admin@careersteps.net`; provision a separate strong `ADMIN_PASSWORD` through a Worker secret. Initial credentials are not included in source.

The page provides separate Calendar, Roster, and Results tabs, editable labeled fields, Add record, Remove record, Reload, Save changes, and Sign out. Users are told these records appear publicly. It does not add private parent records, payment processing, registrations, document uploads, or a new club-management product.

The one-click dashboard adapter is maintained with the Career Steps dashboard under `dashboard/connectors/configs/earthquakes.jsonc` and calls this Worker's existing `/api/site-admin/login` handler through `AUTH_BACKEND`. It requires its own matching connection key. Direct login works independently of the dashboard.

For local validation, run the dashboard's `tools/prepare-earthquakes.mjs` and `tools/prepare-storage.mjs`, its NTX tests, and a Wrangler dry run of this Worker. The checked-in security/query helpers are generated from the dashboard's canonical helpers. This repository can bundle its NTX Worker independently after a standard Wrangler installation. Brent approved release on November 9, 2026. The verified Cloudflare account is pinned; deploying creates a dedicated namespace and applies both SQL migrations atomically at first use. Provision the independent admin secret and verify both public reads and authenticated edits. Local preview uses its own namespace, never production data.

Use the namespace's supported backup/recovery tools and retain a protected export of current content. Rollback can disable the three data routes to expose the original static JSON, but those static files will not contain later admin edits; export current content first. Do not overwrite the original JSON or a live namespace merely to test recovery. An authorized operator can change the `ADMIN_PASSWORD` secret and clear this namespace's sessions if the site password is lost; no self-service reset email is provided.
